# Firebirds Cocktail & More

Storytelling website for the two Firebirds cocktail branches in Da Nang:

- `/` Home: *One spirit. Two ways home.*
- `/stories/tropical-origin` Tropical Origin (*The cabinet that waited*)
- `/stories/vietnam-craft` Vietnam Craft Cocktail (*The alley after rain*)

Includes 4 languages (`EN`, `VN`, `JA`, `KO`), orange/emerald branch hover glows, curated gallery photography, and updated Google Maps links.

## Development & Build

```bash
npm install
npm run check:emdash
npm run build
npm run preview
```
